## 🌟 Featured Projects

### 🗺️ [Unified POI Data Pipeline](https://github.com/BiancaNiemann/Unified_Table_DAG)
> Automated pipeline to validate, standardize, and unify Point of Interest data from multiple sources into a single consolidated dataset for Berlin.

- Enforces schema and data quality checks, excludes invalid tables, and enriches records with **nearest-neighbor spatial relationships** using PostGIS and GIST indexes
- Orchestrated with **Apache Airflow**, containerized with **Docker** — fully reproducible and scalable
- The resulting dataset supports efficient geospatial querying and downstream analytics

`Airflow` `Docker` `PostGIS` `PostgreSQL` `Python`

---

### 📐 [Data Standardization & Spatial Indexing](https://github.com/BiancaNiemann/Unified_Table_Data_Standardization_and_Indexing)
> Standardized and unified multiple database tables into a consolidated schema with spatial intelligence.

- Implemented **nearest-neighbor spatial relationships** and spatial indexing with PostgreSQL GIST indexes
- Stored relationships as JSON for efficient geospatial querying and analysis
- Designed to be reusable and scalable across multiple datasets and spatial layers

`Python` `PostgreSQL` `GIST Indexes` `GeoJSON`

---

### 🌍 [OSM Data Extraction & ETL Pipeline](https://github.com/BiancaNiemann/OSM_Data_Extraction_and_ETL_Pipeline)
> ETL pipeline to extract, clean, and load cultural points of interest from OpenStreetMap for Berlin.

- Utilized **osmnx** and **geopandas** to transform raw geospatial data into structured, analysis-ready datasets
- Includes reusable scripts for automated data ingestion

`Python` `osmnx` `geopandas` `PostgreSQL` `ETL`

---

### 🛒 [Omnichannel E-Commerce Analytics](https://github.com/BiancaNiemann/Data_Analyst_Portfolio_Projects/tree/main/Omnichannel_Ecomm_Project)
> End-to-end analytics project from raw data to interactive dashboard using a modern data stack.

- Built a **star schema** in BigQuery using dbt Core for analytics-ready tables
- Integrated and cleaned multiple data sources, standardizing columns for consistency
- Orchestrated the full ETL workflow with **Airflow**
- Developed an interactive **Looker Studio dashboard** visualizing sales performance, customer behaviour, and channel trends

`dbt Core` `BigQuery` `Airflow` `Looker Studio`
